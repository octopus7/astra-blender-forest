# v2 검증 기록

- 다리: 6,732삼각형. 원본 27,016의 24.9186%.
- 완성형·분리형·공유 메시 3인스턴스 예제·콜리전 GLB: 4개 재로딩 및 수치 검사 통과.
- 각 GLB에 대해 11개 검사 범주. 조립·인스턴싱·중앙 콜리전 간격 3개 검사.
- Python 문법/입력 파일/실제 메시 생성/재현성/노멀/UV/강물 볼륨 등: 43개 검사 통과.
- Blender 스크립트는 GLB 가져오기 대체물이 아니라 실제 메시/UV/PBR 노드/환경/조명 생성 코드.
- 렌더: 전달 GLB를 VTK로 다시 불러온 4개 시점. 환경 배치는 별도의 VTK 근사 미리보기.
- Blender 내부 실행, Cycles 렌더, Unreal 내부 실행: 미검증.
- 공식 Khronos Validator가 아닌 자체 검사.

`03_validate_blender_scene_v2.py`를 Blender에서 실행하면 사용자 환경의 실제 검증 결과를 별도 JSON으로 기록한다. 해당 결과 파일은 아직 생성하지 않았으며, 제작 환경에서 실행한 것처럼 기록하지 않았다.
